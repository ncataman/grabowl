How to Download Facebook Ad Library Videos

The Facebook Ad Library lets you view active ads, but there's no download button. Here's how to save those ad videos in HD, for free.

Get Grabowl FADS for Firefox

Steps

  1. Install Grabowl FADS from the add-ons store.
  2. Open facebook.com/ads/library and search for a Page or keyword.
  3. A green Download HD button appears on each ad — click it.
  4. To grab everything, click Download all on screen.
Tip: the built-in player defaults to SD. Grabowl always saves the true HD file, so you never get a blurry download.
